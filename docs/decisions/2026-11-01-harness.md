## API details learned

- Base URL `https://api.meta.ai/v1`, `Authorization: Bearer $MODEL_API_KEY`, OpenAI-compatible.
- `reasoning_effort` accepts `minimal|low|medium|high|xhigh|max` (not `none`).
- Strict JSON schema: every property must be listed in `required`, and every object needs
  `additionalProperties: false`; free-form objects must be JSON-encoded strings.
- A judge call at medium effort can exhaust `max_tokens` on reasoning and return empty content;
  give off-path calls a generous budget and retry once.
- Transcribe: `POST /v1/asr/transcribe`, multipart parts `request` (JSON with `model`,
  `audioEncoding: "WAV"`, `sampleRateHertz`) and `audio`.
- Images: `POST /v1/images/generations` with `model: "muse-image-1.0"` returns base64 WebP.
- Baseten: `https://inference.baseten.co/v1`, model `meta-models/muse-spark-open-1026`; give it
  room for reasoning (600 tokens was entirely consumed by reasoning).
