## Contracts added

Shared surface for H1–H10. Changing a contract requires a note in your handoff.

- `api/learning/tutor_moves.py` (`tutor-moves.v1`), mirrored in `web/src/lib/tutor-moves.ts`.
  - Twelve move kinds: seg, write, equation, diagram, widget, image, say, predict, check, because, point, turn_end.
  - The discriminator is `type`, as in the planning bake-off; `kind` is a field of widget and check.
  - `move_schema()` / `response_format()` build the strict schema as an `anyOf` of per-kind objects. Every property is required, `additionalProperties: false` is set everywhere, and there is no `$ref`, `const` or `default`.
  - The schema is checked in at `schema/tutor-moves.v1.json`. Regenerate it from `api` with `.venv\Scripts\python.exe -m learning.tutor_moves`; a test fails if the file drifts.
  - Widget specs are JSON-encoded strings. Kinds: `plot` (expr, x range, params of min/max/value), `attention` (tokens and temp; scores are rejected because the widget computes them), `matrix` (≤ 6×6), `stepper` (2–12 LaTeX steps).
- `TurnValidator` checks a turn one move at a time with `accept(raw)` and `finish()`. Its state changes only when a move is accepted, so a repaired move can be re-sent. It enforces:
  - schema and lengths;
  - predict answer in options;
  - mcq key in 2–5 distinct options, and no options for a free check;
  - `because` refs present in the brief (an empty brief rejects every `because`);
  - one check per turn, and a turn with a check must end with `wait`;
  - `wait` only after a predict or check;
  - `turn_end` last, at most 40 moves, unique segment ids;
  - `point.crop` less than the number of crops sent.

  It also restores LaTeX escapes lost to under-escaping, such as form feed + `rac` → `\frac`, tab → `\t`, and `\n`/`\r` only before a known macro tail. `validate_turn()` is the non-streaming wrapper.
- `api/learning/tutor_stream.py`: `MoveStreamParser.feed(chunk)` returns a `ParsedElement` (index, raw, value or error) as each move object closes.
  - It handles chunk splits anywhere, including inside escapes, and braces or brackets inside strings.
  - A malformed element is reported with its raw text (for repair) and the stream continues.
  - Structural damage raises `MoveSyntaxError`; moves already emitted stay valid.
  - `close()` detects truncation. Size and count caps apply.
- `api/learning/learner_contracts.py` (`learner-v1`), mirrored in `web/src/lib/learner-contracts.ts`:
  - `Observation`: concept, dimension (recall|understand|apply|analyze|transfer), outcome, misconception, miss_class (cue|discrimination|execution|careless|structural), assistance, learner confidence, labeler and label confidence, sources. Sources must be learner-authored and at least one is required. A correct answer has no misconception or miss class. The idempotency key is `(session_id, check_id)`.
  - `LearnerBrief`: items with ids `[KSMPN]n` that `because` moves cite, capped at 2,400 characters (about 600 tokens); `.refs` returns the id set.
  - `ProfileRevision`: Beta beliefs per concept × dimension with an optional half-life, a misconception ledger, teaching notes that must cite events, and consumed observation ids.
  - `ConstellationGraph`: nodes with state and a dimension ring, edges that must hit known nodes, and revisions in ascending order. Each revision stores the full state of the nodes it changed; the scrubber replays them.
- `web/src/lib/fixtures/attention-arc.v1.json` is the two-session demo arc. It holds four session-1 observations, profile revision 1, the session-2 brief (K1, S1, M3, P1, N2), a valid session-2 opening turn (predict, attention widget, `because` citing M3/P1/N2, one mcq check, wait), and an 11-node Constellation with revisions 1 and 2. It lives in `web` so H6 can import it, since Turbopack's root is `web`; backend tests read it from there.

- H3: the `plot.expr` charset is restricted (letters, digits, operators, parentheses), but the safe evaluator still has to reject unknown identifiers.
- H4: `Observation.labeler` allows only `deterministic|baseten|none`. Extend it in a noted contract change if TypeSafe labels are needed.
- Line endings: new files are LF in the index with `core.autocrlf` warnings, consistent with the rest of the repo.
