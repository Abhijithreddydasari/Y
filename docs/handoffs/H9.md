## Decisions and changes

- **Proxy-only API.** `ProxyOnly` is plain ASGI middleware. With `LEARNING_PROXY_SECRET` set, every `/learning/*`
  request without `X-Y-Proxy-Secret` gets 403 `proxy_required`; `/health` stays open. The web proxy adds the
  header server-side.
- **Narration.** It tries Deepgram Aura first (`DEEPGRAM_API_KEY`, non-streaming WAV, 4 s timeout). If Deepgram
  fails, times out or is over budget, Kokoro answers, then the browser voice.
- **Budgets.**
  - `CaptureStore.charge` and `limit()` read `Y_LIMIT_*` overrides.
  - Transcription moved from an in-memory window to the DB: 120 per owner and 300 global per hour in prod.
  - Speech (Deepgram) is 600 per owner and 4,000 global per hour.
  - Tutor turns in prod: 150 per hour global, 1,500 per day global, 60 per owner per hour.
  - Close notes already counted against the tutor budget.
- **Legacy calls.** In a production build, `fetchHealth` and `fetchLearner` are skipped unless
  `NEXT_PUBLIC_API_BASE` is set.
- **Identity race (found live, fixed).** A fresh browser fired parallel `/identity` calls, so it minted two
  identities. Later calls carried the wrong cookie and got 401 or 404. The symptoms were "The tutor is
  unavailable", no personas and no Trace. Now one `ensureIdentity()` promise per page is awaited before the
  board, the personas, the tutor options and the profile load. Locally an existing cookie had hidden it.
- **Vercel deploys run from a git-free copy** (`deploy/vercel-prod.cmd`). The Hobby team blocks commit authors
  it does not know.

## Open

- **The first persona build takes about 93 s on hosted Postgres.** It makes thousands of small transactions, and
  each Neon commit is far slower than a local SQLite one. A quick fix is to build the template once, then clone
  its rows in one transaction with `INSERT … SELECT` and fresh ids; that is new code.
  Until then, a judge's first "Try as…" waits about 1.5 min, and later switches take about 2 s.
- **A failed answer turn replays on retry.** Retrying the same card resent the stored failed turn until the page
  was reloaded.

- **Faster first audio from Deepgram.** Use the streaming `speak` endpoint, or send the first clause sooner.
  Also pass `X-Speech-*` through the proxy so the engine can be confirmed.
- **Run the live persona switch and End session before judging**, and record them.
- **Address.** `y.vercel.app` and `ask-y.vercel.app` are taken by other projects; `ask-y-tutor.vercel.app` was
  free at 21:50. An alias needs `vercel alias set <deployment> <name>.vercel.app`, and it was not done.
- **Snapshot.** Cut the Neon `pre-h9` branch now that the schema exists.
- **After judging, scale to zero:** `set "Y_MIN_CONTAINERS=0"`, then `modal deploy`.
